# QE Consultancy (Chromium)

Load this folder unpacked in Chrome / Edge / Brave.

1. Open `chrome://extensions` → Developer mode.
2. **Load unpacked** → select this directory  
   `frontend/extensions/QE-Extension-Dev`  
   (do **not** include a `_metadata` folder if Chrome recreates one — it is local-only).

If the extension was already loaded from `qe-consultancy-chrome` or another path, remove that unpacked copy and **Load unpacked** again from here. The extension ID changes when the folder moves.

See [`../README.md`](../README.md) for origins, Manak PDF API, and version.
